# XLeRobot snack-delivery demo media

These public media files are presentation assets for the EmbodiRun XLeRobot
snack-delivery demo.

- The MP4 is trimmed from the supplied recording at source time **01:00–02:07**.
- The published video is H.264/AAC at 1280×720 for web playback.
- `overview` is a source frame at 01:36, showing the VLA grasp stage.
- `grasp` is a source frame at 01:44, showing the arm holding the snack.
- `return` is a source frame at 01:56, showing the return stage and route UI.

The source recording remains outside this repository. These files contain no
credentials, route files, checkpoints, or deployment configuration.
